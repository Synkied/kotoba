## Design specificity and overall impression

The newsprint stocks, Japanese lettering, sentence balloons, source panels and attempt stamps are authored for this learner’s collect → say → review workflow. Preserve them. The largest opportunity is reliable interaction and readable phone layouts.

The independent bundled detector returned exit 0 and `[]`: zero findings, rules, or locations; no false positives. It did not catch the interaction defects below. No native browser tool was exposed. Final verification uses local Playwright/Chromium with explicit API fixtures, rendered production assets, layout measurements, keyboard interaction and failure injection; no user-visible detector overlay is claimed.

## What works

- Sentences stay connected to their sources across Library, Source, Deck and Practice.
- Empty states usually explain the next useful action, without invented study data.
- Recording states, native/synthetic audio choices and self-grading fit the learning task.

## Priority issues and resolution

1. **P1 — Phone rows squeeze Japanese text or overflow.** Inline desktop grids overrode mobile styles; nonwrapping action groups occupied the reading width. Fixed in Library, Source, Deck, Review and shared CSS: class-based row variants, text-first narrow layouts, wrapped actions, long heading wrapping and 44px touch controls. Suggested repair: adapt/layout.
2. **P1 — Global shortcuts hijack focused controls.** Inbox Enter could keep a different item instead of activating the focused link/button; Practice Space recorded instead of activating a focused control. Fixed with a shared shortcut guard for controls, editable content, composition, modifiers and repeat events. Practice navigation is disabled during recording/scoring/saving. Suggested repair: harden.
3. **P1 — Failed changes appear successful or disappear.** Deck reorder/removal changed the UI before server success; mutations had unhandled rejections; sentence-loading failures looked like empty decks. Fixed with shared locked mutation handling, persistent errors, preserved drafts, server-confirmed updates, retries and safe network/proxy errors. Failed score saving retains a retryable result. Suggested repair: harden/polish.
4. **P1 — Older material is silently inaccessible.** Inbox/Library stopped at 200 sources and deck practice stopped at the default sentence limit; selected practice searched only the first 500 global sentences. Fixed with Load more in source lists, complete deck pagination and explicit selected-ID fetching. Suggested repair: harden.
5. **P1 — Reader dialog does not contain focus.** The fullscreen script reader declared a modal but permitted background focus. Fixed with a native dialog, focus restoration, Escape close and scroll containment; the script textarea is labeled. Suggested repair: audit/harden.

## Personas and cognitive load

- **Sam, keyboard/screen-reader user:** focused controls were intercepted, the reader leaked focus, and the script field was unlabeled. These paths are repaired.
- **Casey, phone user:** sentence actions competed with reading width, controls were small, Speak along was hidden, and setup had no permanent access. These are repaired while retaining the six section tabs.
- **The accumulating Japanese learner:** hidden source limits and inconsistent reading settings made older material and Japanese previews less trustworthy. Pagination and consistent furigana/romaji preferences address this.

Library’s arbitrary label/category chip walls are replaced with a native disclosure and selects, with Clear filters. Source reading and sentence actions now separate cleanly on narrow screens. Practice retains Listen / Say / Next as the core action group.

## Emotional journey

Silent failures created an uncertainty valley after collecting and organizing material. Persistent errors, retryable saves and lasting Undo make outcomes explicit. Session completion uses neutral language; saved-attempt feedback is reserved for confirmed saves.
