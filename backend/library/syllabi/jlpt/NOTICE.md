# JLPT lists

`n1.tsv` … `n5.tsv` (word, reading, meaning) come from
[elzup/jlpt-word-list](https://github.com/elzup/jlpt-word-list) (MIT, © 2020 Jamie Sinclair,
© 2020 elzup), which is built on Jonathan Waller's JLPT lists at
[tanos.co.uk](http://www.tanos.co.uk/jlpt/) (CC BY). The JLPT has published no official
lists since 2010: these are a widely used approximation.

`grammar-n5.tsv` and `grammar-n4.tsv` (pattern, what it does) were written for kotoba.
